# 🤖 AI 학습 리포트

2026.09.09

> 오늘의 TLP와 TIL을 바탕으로 학습 흐름을 간단히 리포트합니다.

## 🧭 종합

Filter·Interceptor·AOP 비교에서 시작해 @Valid 검증과 JWT 발급·검증, Redis Refresh Token, CORS 요청 흐름까지 이어갔다.

## 📝 요약

TLP의 공통 처리 위치, DTO 검증, JWT Secret·토큰·인증 계획이 TIL에서 요청 흐름과 실행 로그 중심으로 연결됐다.

## 📚 주요 학습

- Filter, Interceptor, AOP의 실행 위치와 적용 대상 차이
- @Valid와 Bean Validation 기반 DTO 입력값 검증 흐름
- JWT Header·Payload·Signature 구조와 Claim, 만료 시간, Secret Key 서명
- Access Token과 Refresh Token 역할 구분 및 Redis 저장 구조
- CORS Preflight 이후 JwtFilter, SecurityContext, Controller로 이어지는 인증 흐름

## 👍 잘한 점

- 공통 관심사 처리 위치를 요청 흐름 안에 배치해 JWT 인증에 Filter가 쓰이는 이유까지 연결했다.
- 실행 로그를 바탕으로 OPTIONS Preflight, Bearer Token 검증, Controller와 JPA 호출 흐름을 함께 남겼다.

## 🔧 보완할 점

- DTO 검증 실패 입력과 누락되거나 유효하지 않은 토큰의 실제 응답 비교 기록은 구체적으로 남지 않았다.
